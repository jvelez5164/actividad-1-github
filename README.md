# Actividad 1 - Creación de repositorio en GitHub

Repositorio creado como parte de la Actividad 1 de la asignatura.

## Objetivo

Familiarizarse con el uso de sistemas de control de versiones mediante la creación y gestión de repositorios en GitHub.

## Descripción

En este repositorio se evidencia la creación y configuración inicial de un repositorio en GitHub, así como la incorporación de un archivo README y la realización del primer commit.
